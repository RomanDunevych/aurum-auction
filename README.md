# AURUM AUCTION - Онлайн-платформа аукціонів

## Назва
**AURUM AUCTION** — це повнофункціональна веб-система для проведення онлайн-аукціонів, управління лотами, ставками в реальному часі та користувацькими сесіями. Проєкт відрізняється сучасним дизайном (Glassmorphism UI) та надійною архітектурою.

## Live URL
**[Перейти до сайту](https://aurum-auction-app.onrender.com/)

## Стек технологій
- **Frontend:** React.js, Vite, React Router, CSS3 (Glassmorphism)
- **Backend:** Node.js, Express.js
- **База даних:** SQLite3 (реляційна БД)
- **Деплой:** Render (Cloud PaaS)

## Основні функції
- **Каталог товарів:** Інтерактивний перегляд лотів із сортуванням та фільтрацією за категоріями.
- **Ставки в реальному часі:** Перевірка валідності ставок на сервері, блокування торгів після закінчення таймера.
- **Динамічні таймери:** Автоматичний відлік часу для кожного лоту на основі Unix Timestamp.
- **Рольова модель:** Розмежування прав (Admin — керування лотами; User — участь в аукціоні).
- **Автоматизація:** При запуску порожньої бази система генерує тестовий набір даних для швидкого тестування.

## API Ендпоінти

| Метод | Ендпоінт | Опис |
| --- | --- | --- |
| GET | `/api/lots` | Отримання всіх лотів |
| POST | `/api/lots` | Створення нового лоту |
| DELETE | `/api/lots/:id` | Видалення лоту (Admin) |
| POST | `/api/bids` | Розрахунок ставки |
| POST | `/api/login` | Авторизація користувача |
